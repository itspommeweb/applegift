如何用支付宝购买 Apple 美区礼品卡

📌 使用前要知道的几件事

  • 请确保你已经注册了 美区 Apple ID
  • 支付宝需切换定位为 美国地区（如纽约/洛杉矶）
  • 礼品卡仅适用于 美区账号

🍐 三大平台详细介绍

1️⃣ PockytShop（支付宝内）· 中国
  • 金额起点：$2 起
  • 入口方式：支付宝 → 搜索「PockytShop」
  • 流程：切定位 → 搜索礼品卡 → 付款 → 查看卡密
  • 提示：不建议高频用于 GPT 充值
2️⃣ 卡客风云（kkfaka.com）· 中国
  • 支持金额：$5 / $10 / $25
  • 特点：界面友好，发货速度快，新手可用
3️⃣ SEAGM（seagm.com）· 马来西亚
  • 支持金额：$5 / $10 / $50 / $100
  • 特点：稳定、适合长期充值

🧾 礼品卡使用方法

  1. 登录你的美区 Apple ID
  2. 打开 App Store → 点击右上角头像
  3. 选择「兑换礼品卡或代码」→ 输入兑换码
  4. 可用于内购、Music、iCloud、GPT 等订阅
